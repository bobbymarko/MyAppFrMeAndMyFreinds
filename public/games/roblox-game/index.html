🎮 My Custom Roblox Game

This is a placeholder for your exported Roblox game.

📋 How to Export Your Roblox Game:

  1. Open Roblox Studio with your game
  2. Go to File → Export → Export to Web
  3. Choose a location to save the exported files
  4. Copy all exported files to this directory: public/games/roblox-game/
  5. Replace this file with your exported index.html

📁 Required Files After Export:

  • index.html - Main game file (replace this one)
  • *.js - JavaScript game files
  • *.wasm - WebAssembly files
  • *.pck - Game data files
  • *.png - Images and icons

✅ Once Exported:

Your game will automatically load when you select "My Custom Game (Local)" from the dropdown above!
